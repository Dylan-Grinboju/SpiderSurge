# SpiderSurge features

Every player-facing feature with a quick live check, its code, and what it shares code or patch targets with. SKILL.md uses it to pick neighbours and random checks, and `pick.py` reads it, so keep one row per feature and the column order as it is.

Keep it current: when a change adds, removes or changes a feature, update its row in the same QA run. Written 2026-10-19 from `main` plus the fixes in PR #54. Paths are relative to the SpiderSurge worktree root.

Shorthand used in the checks (all through SpiderInspector):

- **Surge run**: `act/start?mode=survival&surge=1`, then `act/freeze?waves=1`, then pause. Abilities only attach to spiders that spawn while a Surge run is active.
- **Grant X**: `call type=PerksManager method=OnSelected args=X` (X is `pulse`, `pulseUltimate`, `immune`, ...).
- **Set perk X N**: `call type=PerksManager method=SetPerkLevel args=X,N`. Vanilla perks: `act/modifier?name=X&level=N`.
- **Cast**: tap LB on the pad. **Cast ult**: `call type=<Ability> player=0 method=ActivateUltimate` (or L3+R3 together, or C for a keyboard player).
- SpiderInspector's own enemy freeze locks bodies, so unfreeze (`act/freeze?enemies=0`) before a cast that should move enemies.
- The game is muted on launch; unmute for sound checks. Keep `surge.telemetry` off unless the check is about telemetry, or the run goes to the live relay.
